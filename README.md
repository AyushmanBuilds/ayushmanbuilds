# Ayushmanbuilds — Premium Light-First Website Revamp

A from-scratch static redesign for Ayushmanbuilds, built around a white editorial canvas, electric-blue brand system, elevated UI surfaces and restrained 3D motion.

## Included pages
- `index.html`
- `about.html`
- `services.html`
- `portfolio.html`
- `testimonials.html`
- `contact.html`
- `service-website-development.html`
- `service-seo-optimization.html`
- `service-ecommerce-solutions.html`
- `service-web-applications.html`
- `service-website-revamps.html`
- `service-automation-workflows.html`

## Main enhancements in this revision
- Light mode is the default visual theme.
- Persistent dark-mode toggle is available from the modern floating navbar on every page.
- Navigation uses a glass/pill system with blue hover states, animated underline treatment and a responsive services dropdown.
- **My CA Locker** is the first featured project in Work and links to `https://mycalocker.vercel.app`.
- The portfolio uses a featured SaaS treatment for My CA Locker and retains the remaining project cards.
- Every service detail page now includes a multi-image editorial gallery with service-specific imagery.
- The Services landing page also uses image-led capability cards.
- Home and Reviews pages include a slow, pause-on-hover scrolling testimonial rail.
- The existing 3D hero, floating interface elements, hover tilt, scroll reveals, project modal and responsive layouts remain part of the system.
- User-supplied Ayushmanbuilds logo is used throughout the brand UI and favicon.

## Technical
- Static HTML/CSS/JS
- Three.js CDN for the lightweight hero scene
- No build step required
- Responsive across desktop, tablet and mobile
- `localStorage` stores the selected light/dark mode
